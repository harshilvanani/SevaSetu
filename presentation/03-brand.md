# Brand and visual style

Taken from the SevaSetu app's own design system (Art of Living theme).

## Colours
| Name | Hex | Use |
|---|---|---|
| Plum | `#3C285F` | Title and section slides, dark panels, the app's sidebar |
| Purple | `#8441AB` | Accents, links, selected items, chart lines |
| Purple dark | `#5E2E7E` | Purple text on light backgrounds |
| Purple tint | `#F3EAF8` | Soft panels, diagram boxes |
| Sunrise orange | `#FF9800` | Small highlights (logo "setu") |
| Deep orange | `#F17225` | Progress bars, "needs attention" |
| Orange text | `#D9590B` | Orange text on cream |
| Amber tint | `#FFF1D9` | Soft warm panels |
| Cream | `#FDFBF7` | Content slide background |
| Charcoal | `#222222` | Headings and body text |
| Body grey | `#525252` | Secondary text |
| Border | `#EEE7DD` | Card borders, dividers |
| Success green | `#1F6B3A` on `#E3F2E7` | "Done", "passing", "active" |
| Danger red | `#8C2F22` on `#F9E4E0` | "Urgent" only |

Logo colours: "seva" `#650DB5`, "setu" `#FD8602`. On plum backgrounds write "seva" in white.

## Fonts (Google Fonts)
- **Headings:** Lora SemiBold (serif).
- **Body, labels, numbers:** Poppins (400 regular, 500 medium, 600 semibold).
- **Overlines and slide labels** ("POINT 3 · AWS"): Poppins SemiBold, uppercase, letter-spacing about 0.12em, purple.

## Logo
- `logo/sevasetu-logo.png`: full logo. Use it on the title slide and in a small footer corner.
- `logo/logo-mark.png`: sun-and-bridge mark only. Use it as a small icon.
- Keep clear space around the logo; don't stretch or recolour the mark.

## Style
- Rounded cards (radius about 16px), thin warm borders (`#EEE7DD`), very soft shadows.
- Generous white space; at most 5 bullets per slide.
- **Charts:** one hue (purple) for magnitude; orange only to flag something needing attention; label values directly.
- **Diagrams:** use the provided PNG/SVG files; they already use the brand purples.
- **Icons:** simple outline icons (1.5–2 px stroke), purple or charcoal.
- **Don't:**
  - use stock photos of people pretending to be volunteers
  - use bright gradients
  - use emojis as bullets
  - suggest SevaSetu is already on AWS
